# Lembrete de água

Aplicativo que lembra de beber água em intervalos ajustáveis, com sincronização
entre aparelhos, aviso com a tela bloqueada, histórico e contagem de goles e
mililitros.

A página é servida pelo GitHub Pages, em
https://isabellavfortunato.github.io/beberagua/ , e o motor (banco de dados
Firestore, função agendada de envio e notificações) roda no projeto Firebase
beberagua-a7e50. Enviar arquivos para este repositório publica o site
automaticamente.
